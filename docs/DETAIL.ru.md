# kore-plugin-redis (плагин управления Redis)

## Что делает плагин

Подключается к существующим экземплярам Redis пользователя и предоставляет обнаружение экземпляров, информацию, просмотр ключей, чтение/запись и управление TTL, удаление, четыре режимных представления только для чтения (персистентность, память, slowlog, keyInfo) и изменение конфигурации сервера из списка разрешённых. Не содержит сервер Redis или клиентскую библиотеку (G-05/G-17).

Методы: redis.instances, redis.info, redis.keys, redis.get, redis.set, redis.delete, redis.ttl, redis.expire, redis.persistence, redis.memory, redis.slowlog, redis.keyInfo (полные таблицы в DETAIL.md).

## Ключевые моменты

- Клиент — минимальная реализация RESP примерно на 200 строк в internal/redisop (net.Dial и CRLF-кодек); redis-cli на хосте не требуется.
- Короткие соединения: одно TCP-соединение на вызов, закрываемое по завершении; нет постоянных соединений, фоновых опросов и утечек горутин.
- Протокол kore.plugin.v1, lifecycle=lazy, depth_level=production; 16 бизнес-методов и два config-метода объявляют возможности на уровне метода (чтение system:read, запись system:admin); stdout зарезервирован для кадров протокола, журналы — в stderr.
- Учётные данные передаются через окружение/конфигурацию и никогда не попадают в журналы или README; цели подключения ограничены списком разрешённых экземпляров, изменения конфигурации — только разрешёнными ключами.

## Установка и проверка

Установите `redis` из маркетплейса плагинов или импортируйте dist/redis-0.6.0.tar.gz, собранный через make dist. Проверка: make check (gofmt, go vet, go test -timeout 200s), включая наборы boundary и fault.
